# Categorical Syllogism Venn Diagrams  
  
## Summary  
In modern logic Venn diagrams are used to test the validity of [[Categorical Syllogism]]s. 
## Notes  
- For *universal propositions*: **shade** the area that is empty
- For *Particular propositions*: *put an X* to area that contains something
- For Syllogisms first create a Venn diagram for the conclusion then for the 3 terms in the propositions
- ==Always shade the universal proposition first==
