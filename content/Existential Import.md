# Existential Import  
  
## Summary  
[[Existential Import]] of [[Categorical Proposition]]s is the *implications* of the truth value of the proposition *about what exists*. 
If we accept that Universal [[Categorical Proposition]]s have [[Existential Import]], a universal proposition being true means that *that thing exists*, which is the Classical understanding. If all S are P => S exists

In Modern Logic Universal [[Categorical Proposition]]s **does not** have [[Existential Import]], a universal proposition being true simply means that its **contradictory**[^1] is false. If All S are P => ~~Some S are not P~~

## Notes  

1. [[Square of Oppositions]] necessitates [[Existential Import]] for Universal [[Categorical Proposition]]s. without it, it doesn't work
2. In *Modern Logic* only *Particular Propositions* has [[Existential Import]]
3. Modern Logic is the Logic of Venn Diagrams. Universal statement shows where is empty and don't give info about if other parts of the diagram have members![[Pasted image 20260802155356.png]]
4. Thus both *All S are P* and *No S are P* can be true at the same time. which undermines the **Contrary** principle in the [[Square of Oppositions]]![[Pasted image 20260802160014.png]]
5.  Rule 5 of *Modern Logic*: If the conclusion is Particular, at least one of the propositions should be Particular too.
6. There are more valid arguments in the **Classical Logic** than the **Modern Logic**
