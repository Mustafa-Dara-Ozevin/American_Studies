# Existential Import  
  
## Summary  
[[Existential Import]] of [[Categorical Proposition]]s is the *implications* of the truth value of the proposition *about what exists*. 
If we accept that Universal [[Categorical Proposition]]s have [[Existential Import]], a universal proposition being true means that *that thing exists*, which is the Classical understanding. If all S are P => S exists

In Modern Logic Universal [[Categorical Proposition]]s **does not** have [[Existential Import]], a universal proposition being true simply means that its **contradictory**[^1] is false. If All S are P => ~~Some S are not P~~
