# Thought  
  
### Thought as Characterization

*Thought reveals:*
- Desire 
- fear 
- memory 
- conflict
- moticvation
- uncertainty
- self-deception
- decision-making

*Thought can also:*
- Create mood
- develop theme
- move the action forward


### Contradiction

Don't eliminate contradictions Use them to create character.
