# Characterization  
  
## Summary  

Character are main workhouses that make the stories come alive and move them
## Notes 
- They should be ineteresting, beliveable, emotionally significant
- How can a writer show us who a character is without simply explaining who theyt are?
- 4 direct methods:
	- [[Dialouge]] => What does the character say?
	- [[Appearance]] => What does the character look like\possess?
	- [[Action]] => What does the character do?
	- [[Thought]] => What happens inside the characters mind?

- Characterization => Creating the reader's understanding of a character

### Character Desire

| want     | need      |
| -------- | --------- |
| External | Internal  |
| Known    | Unknown   |
| Plot     | Theme     |
| Fun      | Heart     |
| Unique   | Universal |
Push your character to the character and create drama. conflict of inner values.

- What does the character want?
- What does the character want right now?
- what prevenrts them from getting it?
- What choice do they make?
- What happens because of that choice?

*Character:*
Desire -> Thought -> Choice -> Action
